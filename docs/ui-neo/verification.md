# SERIES Neo 风格 UI 改版记录

验证日期：2026-10-18。仅修改前端和前端 Mock；未改 Go、norma、业务接口、数据库或权限规则。未提交 Git、发布或重启业务服务。

## 已实现

- 全站采用中性浅灰背景、白色面板、细边框、深色主按钮；兼容深色模式与现有本地字体。移除全局 5px 圆角覆盖和旧布局预设入口。
- 248px 可折叠侧栏，移动端抽屉；主要业务入口与运行记录分组，底部设置、外观和账户。保持左上角无 LOGO。
- 新默认入口 `/function/tasks/new`：描述与附件 → 目标及配置 → 显式创建。完整保留原创建表单字段，模板不自动创建任务。
- 8 个设置栏目按需加载，桌面左右分栏弹窗，手机全屏；关闭卸载当前栏目。使用 `settings=1&settingsTab=...`，保留任务、会话、来源和筛选参数。
- 编辑器未保存修改在切换栏目或关闭时提示；维持各栏目独立保存、即时开关等原有语义。嵌套编辑器、下拉框及 Esc 保留独立层级。
- 任务会话与独立聊天共用中性气泡、输入框和消息样式。数据表格、按钮、面板、登录与初始化页同步使用共享视觉规范。
- Ctrl/Cmd+J 新任务；避让输入框、中文输入和编辑弹窗。按后续需求移除侧栏功能搜索及 Ctrl/Cmd+K 绑定；页面筛选和会话搜索快捷键不变。

另外使用当前前端的临时副本（`NEXT_PUBLIC_MOCK=0`），连接本地模拟 HTTP API。该实例实际经过 fetch、Next 代理及 EventSource，完全不连接业务数据库：

- 成功走登录 → 新首页 → 创建失败 → 重试成功 → 任务会话。
- 会话仅建立 **1 条 SSE**；打开设置、切到模型并关闭，未发生断连、重连或历史重新读取。
- 关闭设置后继续观察 **52 秒**：系统配置、入口认证设置、版本、模型配置及模型池没有新增请求；原任务轮询继续。
- 测试用监听端口 3002、3003、18333、18334 已停止；原 Mock 服务未重启。

局限：HTTP API 与 SSE 数据来自本地模拟服务，不代表 Go 后端或生产网络压测。迟到结果、分页、详情重试等复杂组合沿用相关自动回归，本轮未逐一在真实 Go 服务中复测。

## 请求与构建体积

### 默认首页请求

改版前为任务列表，改版后为新建任务页。对两份源码使用相同的隔离 HTTP Mock API，在第一次非认证 GET 后取 3 秒窗口。Next 开发模式启用 React Strict Mode，包含重复挂载请求；不含静态文件、认证请求及之后的周期轮询。

| 指标 | 改版前 | 改版后 |
| --- | ---: | ---: |
| API 请求 | 14 | 4 |
| 不同 API 路径 | 7 | 2 |

改版后初始只请求审批计数与模板；模型、企业、已有任务和分类在进入配置阶段后分别请求一次。关闭设置时不预取各设置栏目。两种默认首页承担的功能不同，这组数字不等于同一业务任务的耗时提升。

### 生产静态构建

按各路由 HTML 中去重后的初始 script 文件统计，gzip 为逐文件 gzip 之和，单位为字节；不包含运行时按需加载的全部脚本，不是浏览器传输耗时。

| 路由 | 初始脚本数 前→后 | JS 原始字节 前→后 | gzip 字节 前→后 |
| --- | --- | --- | --- |
| 任务列表 | 24→23 | 1,567,406→1,388,696 | 480,430→422,617 |
| 任务会话 | 27→27 | 1,856,313→1,844,215 | 574,717→570,415 |
| 系统配置 | 23→22 | 1,286,727→1,278,260 | 394,201→390,379 |
| 独立聊天 | 26→25 | 1,623,442→1,614,034 | 498,999→495,485 |
| 新建任务 | 新增，23 | 1,408,977 | 433,331 |

静态产物总量 7,725,017→7,955,477 字节（+2.98%）；全部 JS 为 5,544,057→5,767,538 字节（+4.03%）。新增页面与动态设置容器增加总构建量，主要现有路由初始 JS 未增加。原始记录见 [构建指标](./build-metrics.json) 和 [请求指标](./request-metrics.json)。
