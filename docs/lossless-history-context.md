# 无损日志历史表示

本次用无损表示替代上一轮失败的首尾预览方案。完整证据仍在当前模型请求中，无需模型主动补读才能获得被删去的中间内容。结构共享会改变表达形式，因此仍须真实模型验证，不能把“可还原”直接等同于“模型必然理解正确”。

## 运行行为

- 仅处理 Bash、Monitor、Grep、Glob、LS 成功返回的单个纯文本块。Read 源码、结构化 JSON、错误、多内容块等保持原样。
- 候选正文 12000 字节至 4 MiB。连续至少 8 行的重复赋值结构，或共享的行前缀/后缀，可转成 `parts + rows`；非匹配行完整保留在 `text` 中。
- 所有值均保留为字符串，不解析或重新格式化数字、URL、Unicode、空白和行尾。只共享重复格式，保持行顺序。
- 每次变换后重新构造全文，必须与原文逐字节一致；每组及整体至少节省 15% 字节，否则保留原文。字节节省不等于计费 token 节省。
- 通用分组最多查看 512 行，不获益的已扫描段直接保留，避免逐行重复扫描导致平方级开销。
- 明确输出上限至少为 8192 时才启用；预算较低或为 0（服务端默认预算未知）时保留原文，不提高调用方预算。阈值是平台保守策略；真实模型最终验证使用任务 160 实际请求的 32768 输出上限。

投影位于授权过滤与既有结果去重之后，保留 NOA 引用后缀，不改变审计、工具参数、调用 ID、思考字段或原压缩器。相同原文产生相同投影，不随消息轮次重新选择摘要。

## 为什么保留低输出预算回退

开发阶段在 4000 token 的测试预算下，曾出现正确 URL 已取回，但回答在 JSON 中途结束，未完成其他字段的案例；另一批基线也出现了任务失败。不能据此把所有失败都归因于压缩，也不能把正确证据已经出现当作任务完成。本次保守地让较低显式输出预算保留原文，并以实际任务预算验证最终方案。

## 验证口径

`TestLiveLosslessHistoryComparison` 使用同款生产模型 deepseek-flash，thinking=enabled、reasoning_effort=high，处理隔离 PostgreSQL 中的合成历史，不执行生产命令。四类任务分别要求中间证据值、压缩后继续执行、表格中的精确字段值、完整 URL；同时验证已完成的写入回执和只读下一步。

两组使用相同工具与原压缩器。压力测试窗口为 64000，不修改生产窗口。最终测试用每组独立、组内稳定的系统前缀隔离跨组缓存，摘要请求同样隔离并计入总用量。交替执行前后两组；明确要求三个字符串字段，按 JSON 解析后的精确值验收，避免把对象或额外标签与错误证据混为一谈。业务验收失败会使测试失败。

指标口径：任务完成要求完整 JSON、精确证据值、写入回执及下一步约束全部通过；工具参数成功表示调用未返回执行错误或条目错误，不代表最终答案正确。重复读取仅统计同一工具及规范化参数完全相同的再次调用，不涵盖语义重复或片段重叠。未缓存输入按每次响应的 `InputTokens - CacheReadTokens` 累加，输出 token 单列，不把输出开销隐藏在输入节省中。

工程测试覆盖逐字节还原、异常行、中文和 CRLF、重复日志计数、无效输入回退、低输出预算回退、既有重复结果去重、流式/非流式与 NOA 引用。另有模糊测试与任务 160 原始请求离线重放。

任务 160 的 38 份 Worker 样本中，5 份请求命中，工具结果文本由 2480966 字节降至 2453742 字节，约减少 1.10%。这是样本中可解析文本的字节变化；原始协议缺少 IsError，覆盖率按上界解释。不能据此宣称整个任务 token 减少相同比例。

最终真实模型结果见配套评测汇总；样本规模有限，不代表所有任务准确率均为 100%。完整过程记录保留在本地 `docs/verification/lossless-history-20261121/`，不包含 API Key。

## 复现方式

评测通过 `liveeval` 构建标签启用；必须显式提供隔离 PostgreSQL 的 `SERIES_PG_DSN`，不会默认连接应用数据库。模型配置文件通过 `ARTEX_LIVE_CONFIG` 读取；不要把凭据提交到仓库。设置 `ARTEX_LIVE_OUT` 保存合成记录，设置唯一的 `ARTEX_LIVE_CAMPAIGN` 隔离其他批次缓存，`ARTEX_LIVE_REPEATS=3` 执行 12 对案例。

```sh
go test -tags liveeval ./agent \
  -run '^Test(LiveLosslessHistoryComparison|LosslessLiveAnswerValidation)$' \
  -count=1 -v -timeout=20m
```

离线重放通过 `ARTEX_HISTORY_REPLAY` 指向已获授权的原始请求目录，再运行 `TestLosslessHistoryRecordedReplay`。它只验证可还原性和字节变化，不调用模型，也不测量实际计费 token。
